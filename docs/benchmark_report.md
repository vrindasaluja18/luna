## Resource budget

| metric | value | target |
|---|---|---|
| peak RSS | 19 MB (proc-poll) | < 5 GB |
| simulated duration | 30 s | - |

Peak RSS is for a single reference run and includes process startup. A
`gnu-time` reading is the kernel high-water mark; a `proc-poll` reading
samples VmHWM and can miss a spike between samples, so treat it as a
lower bound. The 8 GB budget is a hard constraint on the whole stack; the
simulator is the heaviest component because it holds the world grid and
landmark field.
