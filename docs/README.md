# Documentation

The published site is <https://vrindasaluja18.github.io/luna/>, served from the
`gh-pages` branch (not from this directory). `gh-pages` holds the project
landing page at `/` and the note at `/blog/`.

- `index.html`, `style.css`, `flow.js` - the working source of the `/blog/` page,
  a hand-built page with an animated data-flow diagram. No frameworks, no CDN.
  The particle speed is scaled by each stage's resident bytes, so the flow
  visibly bottlenecks at the Morse topology stage. Copy these into the
  `gh-pages` branch under `blog/` to publish; `.nojekyll` keeps Jekyll from
  processing the files.
- `GOAL.md` - what the project is for, its sub-goals and their measurements, and
  the honest map of which reinforcement-learning roles exist and which do not.
- `benchmark_report.md` - generated by `make bench`. Do not edit by hand; every
  number comes from a run of the built binary.
- `blog/01-liquid-memory.md` - the research note: two principles (maths over
  prose; every computation must earn its place), the finding that the Morse
  topology module is already persistence-based clustering, the three candidate
  "flows" and which of them Luna actually has, and the phased plan.

The technical report, C++ API reference, and figures referenced by the project
plan are not written yet.
